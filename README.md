# Kiafekoi ? — Présidentielle 2027 (stop ou encore)


Jouer : https://francoquecigrue.github.io/kiafekoi/
Jeu web mobile, sans dépendance. Ouvrir `index.html` ou publier via GitHub Pages.

- `data.js` : candidats, questions et explications. Les faits datent du 13/11/2026 et sont à mettre à jour avec l'actualité.
- `game.js` : réglages en haut du fichier (`GAME_DURATION`, `STEP`).
- `photos/<id>.jpg` : photo d'un candidat. Sans photo, les initiales s'affichent.
- `audio/<id>.mp3` : son joué au clic sur un candidat. Sans fichier, un bip synthétique propre au candidat est joué.

Identifiants : lepen, melenchon, philippe, attal, retailleau, glucksmann, zemmour, roussel, tondelier, arthaud, nda, lisnard.

Droits : n'utilisez que des photos et extraits dont vous avez les droits ou qui sont sous licence libre (Wikimedia Commons, avec attribution).
