# Qui est concerné ? — Quiz présidentielle (stop ou encore)

Jeu web mobile, sans dépendance. Ouvrir `index.html` (ou publier via GitHub Pages).

- `data.js` : candidats et questions (modifiables).
- `game.js` : règles (`GAME_DURATION`, `STEP`, `REVEAL_MS` en haut du fichier).
- `photos/<id>.jpg` : photo d'un candidat (sinon initiales). Utiliser des images dont vous avez les droits (ex. Wikimedia Commons, avec attribution).
